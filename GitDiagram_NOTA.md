# Nota sobre GitDiagram

Los archivos `.md` de `docs/` contienen diagramas Mermaid editables. GitHub puede renderizar Mermaid dentro de Markdown.

`MediSalud_GitDiagram.md` reúne los diagramas en un solo documento.

GitDiagram puede analizar la estructura del repositorio para generar su propia visualización; estos archivos no obligan a GitDiagram a mostrar exactamente los diagramas Mermaid como su diagrama principal.
